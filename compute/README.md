# compute (Modal workloads)

GPU model serving and batch jobs that run on Modal. They import the engine package
(`ledger_rag`) so chunking, rendering and scoring match serving exactly. Every run is
authenticated with `ledgerctl modal`, and paid runs need explicit authorization
([AGENTS.md](../AGENTS.md)).

| File | Kind | Purpose |
|---|---|---|
| `inference.py` | serving | TEI embeddings and reranker endpoints |
| `reranker.py`, `qwen3_reranker.jinja` | serving | Qwen3 reranker on vLLM |
| `llm.py`, `llm_middleware.py` | serving | Self-hosted Qwen LLM on vLLM behind bearer auth |
| `decisions.py` | serving | Laya routing/turn decision endpoint |
| `verifier.py` | serving | LettuceDetect groundedness verifier |
| `ingestion.py` | job | One-container GPU chunk, embed and Qdrant upload |
| `evaluation.py`, `llm_bench.py` | job | FinQA evaluation and LLM serving benchmarks |
| `summaries.py` | job | Cached contextual chunk summaries (v3 profile) |
| `training.py` | job | Embedding fine-tuning, export and parity |

Conventions every app follows (enforced by `compute/tests/test_modal_contract.py`):

- **Dependencies:** images that run engine code install `requirements/engine.txt`
  (or `engine-train.txt`), hash-pinned exports of `uv.lock` generated by
  `scripts/export_requirements.py` and checked in CI. `Image.uv_sync` is not used:
  it does not support uv workspaces.
- **Secrets:** an app attaches only Modal Secrets that `ledgerctl push` delivers, and
  each required key must be routed to that Secret in `config/secrets.toml`.
- **Naming:** apps and volumes are `ledger-*`. Volumes: `ledger-data` (datasets,
  reports, manifests), `ledger-models` (trained artifacts), `ledger-hf-cache`,
  `ledger-llm-hf-cache` and `ledger-llm-vllm-cache` (model caches).
- **Cost:** GPU functions scale to zero (`min_containers=0`) unless a warm tier is
  explicitly configured, and GPU lists allow fallbacks (e.g. `["L4", "L40S"]`) for
  availability. Region pinning is deferred until the Qdrant and engine regions are
  fixed, because narrow regions cost up to 1.75x.
- **Data:** jobs fetch datasets through the shared, SHA-256-verified registry
  (`ledger_rag.evaluation.datasets`), never ad-hoc downloads.

Runbooks: [ingestion](../docs/INGESTION.md), [evaluation](../docs/EVALUATION.md),
[operations](../docs/OPERATIONS.md#optional-self-hosted-inference).
